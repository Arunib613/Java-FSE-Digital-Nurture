Angular Project Notes

1. angular.json
   - Contains the Angular workspace configuration including build, serve, test, assets, styles, and project settings.

2. tsconfig.json
   - Main TypeScript configuration file shared across the Angular project.

3. tsconfig.app.json
   - TypeScript configuration specifically used when compiling the application source code.

4. package.json
   - Contains project information, dependencies, npm scripts, and package versions.

5. src/main.ts
   - Entry point of the Angular application that bootstraps the root standalone component.

6. src/app/app.config.ts
   - Provides the application-wide configuration such as routing and dependency providers for standalone Angular applications.

7. src/app/app.component.ts
   - Defines the root component of the Angular application, including its logic and metadata.

8. src/index.html
   - The main HTML page loaded by the browser that hosts the Angular application.
